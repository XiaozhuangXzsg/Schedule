# 更新日志

所有版本的发版说明都写在这里；Release 工作流会读取对应版本段落作为 Release 说明与客户端更新弹窗的内容。

## [3.1.0] - 2026-11-01

娅娅课表 3.1.0 正式版（新增「液态玻璃」视觉风格，可在个性化里开关）。

- 新增「液态玻璃（Apple Liquid Glass）」视觉风格，默认关闭，可在「设置 → 个性化 → 液态玻璃风格」开关，
  切换后立即生效，不需要重启，也不改动任何业务逻辑与数据结构；
- 玻璃面板改为三层叠加：真半透明底色（纵向渐变模拟厚度）、斜向镜面扫光、底部接触阴影；
  边缘换用更亮的渐变描边，卡片另外加一层柔和外投影，让玻璃"浮"在背景上；
- 页面背景新增环境光：以主题色为主光、强调色为副光、次级色压底，三团径向柔光聚在角落，
  玻璃压在哪里，透上来的就是那一小片颜色（环境色彩渗透）；
- 卡片、胶囊、弹窗、开关、下拉这些容器统一走同一套玻璃材质，深浅色各有一套透明度配比；
- 底部胶囊指示器、图标缩放、开关回弹与子页转场统一接入系统「减少动态效果」设置，
  开启后动画退化为瞬时切换；
- 关闭液态玻璃即回到原来的凝光样式，两套观感可以随时对比。

## [3.0.0] - 2026-11-01

娅娅课表 3.0.0 正式版（首个正式版，版本号从 2.2.1 直接进入 3.x，界面上的版本号统一带「正式版」标识）。

- 版本号进入 3.x：`versionName` 3.0.0 / `versionCode` 30000；界面（设置页当前版本、关于、更新弹窗）
  统一显示「v3.0.0 正式版」，避免和 2.x 的四位版本号混淆；
- 新增应用内更新：启动后后台检查 GitHub Releases（默认每天最多一次），设置页也可手动「检查更新」；
- 使用 versionCode 判断新旧，忽略草稿与预发布版本；
- 只采用同时附带 `version.json` 元数据的 Release：3.0.0 之前的历史发布用另一套版本号算法（v2.2.1 = 221），
  按新算法会算成 20201 并永远排在新版本之前，因此这些 Release 被明确排除，不会误报「有新版本」；
- 更新弹窗展示当前版本、最新版本、更新说明与安装包大小，可选择「立即更新」或「稍后再说」；
- 下载显示实时进度与速度，支持中断重试与 Range 续传；
- 安装前校验 SHA-256、包名、versionCode 与签名，任一不通过即拒绝安装；
- 通过系统安装器覆盖安装，不卸载旧版，不清除数据库与设置；
- 新增「导出数据备份 / 导入数据恢复」，可保存到系统文件选择器指定的任意位置；
- 数据库迁移策略调整：不再对已有用户库默认启用破坏性迁移；
- 修正设置页与说明弹窗中失效的 GitHub 仓库链接。
