# 更新日志

所有版本的发版说明都写在这里；Release 工作流会读取对应版本段落作为 Release 说明与客户端更新弹窗的内容。

## [1.0.0] - 2026-11-01

娅娅课表 1.0.0 正式版。

- 新增应用内更新：启动后后台检查 GitHub Releases（默认每天最多一次），设置页也可手动「检查更新」；
- 使用 versionCode 判断新旧，忽略草稿与预发布版本；
- 只采用同时附带 `version.json` 元数据的 Release：1.0.0 之前的历史发布用另一套版本号算法（v2.2.1 = 221），
  按新算法会算成 20201 并永远排在新版本之前，因此这些 Release 被明确排除，不会误报「有新版本」；
- 更新弹窗展示当前版本、最新版本、更新说明与安装包大小，可选择「立即更新」或「稍后再说」；
- 下载显示实时进度与速度，支持中断重试与 Range 续传；
- 安装前校验 SHA-256、包名、versionCode 与签名，任一不通过即拒绝安装；
- 通过系统安装器覆盖安装，不卸载旧版，不清除数据库与设置；
- 新增「导出数据备份 / 导入数据恢复」，可保存到系统文件选择器指定的任意位置；
- 数据库迁移策略调整：不再对已有用户库默认启用破坏性迁移；
- 修正设置页与说明弹窗中失效的 GitHub 仓库链接。
